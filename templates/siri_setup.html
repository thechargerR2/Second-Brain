Siri Shortcut Setup

Say "Hey Siri, Second Brain" to ask questions with your voice.

1

Open the Shortcuts app

Tap the + button to create a new shortcut. Name it "Second Brain".

2

Add "Dictate Text"

Search for and add the Dictate Text action. This captures your spoken question.

Set "Stop Listening" to After Pause so it waits for you to finish speaking.
3

Add "Get Contents of URL"

Search for and add Get Contents of URL. Configure it exactly like this:

URL
Method
POST
Headers
Content-Type : application/json
Request Body
JSON
Body fields
question : set to Dictated Text (tap the variable)
provider : claude
4

Add "Get Dictionary Value"

Add Get Dictionary Value. Set the key to answer. Set "in" to Contents of URL.

5

Add "Speak Text"

Add Speak Text. It will automatically use the dictionary value from the previous step. Claude's answer will be read aloud to you.

6

Optional: Show the answer too

Add Show Result after Speak Text so you can also read the answer on screen.

Usage: Say "Hey Siri, Second Brain" and it will prompt you to speak your question. Claude will search your notes and speak the answer back.

Rename tip: You can rename the shortcut to anything — like "Ask my notes" or "Research assistant" — and Siri will respond to that phrase instead.
